# Code review geral

`code-review@1.1.1` fornece uma skill independente de repositório e workspace. Combina
Standards, Spec, reprodução de defeitos e revalidação do head. Publica somente
BLOCKER/MAJOR comprovados quando a tarefa autoriza; não fabrica comentários nem faz merge.

O processo foi adaptado da skill review versão 2.0.0 do usuário, preservando os princípios
necessários sem configurações pessoais. Origem e hash estão na referência da skill.
Os archives anteriores permanecem imutáveis. A skill funciona sem dependência de
um pacote de agentes.

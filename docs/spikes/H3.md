# H3 — Claude Code com streaming contra um proxy simples de `/v1/messages`

**Veredito: parcial.** Repasse da credencial do próprio cliente: **confirmado**. Injeção da chave da organização:
**pendente, precisa de `ANTHROPIC_API_KEY`** (Claude Code 2.1.305, 2026-10-20).

## Objetivo
Verificar se o Claude Code funciona com streaming via `ANTHROPIC_BASE_URL` apontando para um proxy Node (porta 8787)
que repassa `POST /v1/messages` a `https://api.anthropic.com` sem buffer.
Código: `spikes/h3/proxy.mjs`. O proxy registra só nomes de headers e o tamanho das credenciais.

## Comandos e saída
```
$ node spikes/h3/proxy.mjs &
$ ANTHROPIC_BASE_URL=http://127.0.0.1:8787 claude -p "responda só OK"
OK
# log do proxy
POST /v1/messages?beta=true headers: accept,authorization(len=115),content-type,...
upstream 200 text/event-stream; charset=utf-8
```
O Claude Code logado por claude.ai (`claude auth status`: `authMethod: claude.ai`; sem `ANTHROPIC_API_KEY` no
ambiente) envia `Authorization` ao `ANTHROPIC_BASE_URL` customizado. O proxy repassou e a resposta voltou em SSE.

Streaming:
```
$ ANTHROPIC_BASE_URL=http://127.0.0.1:8787 claude -p "Conte de 1 a 30..." \
    --output-format stream-json --verbose --include-partial-messages
text_delta_events=8 first=3.39s last=4.06s
```
Os deltas chegaram numa janela de 0,67 s, não todos no fim. É compatível com ausência de buffer, mas não é
comparação com chamada direta.

Cliente com token próprio:
```
$ ANTHROPIC_AUTH_TOKEN=<22 caracteres> ANTHROPIC_BASE_URL=http://127.0.0.1:8787 claude -p "responda só OK"
authorization(len=29)      # "Bearer " + 22; upstream 401, esperado (token inválido)
```
`ANTHROPIC_AUTH_TOKEN` chega como Bearer ao proxy. Com ele definido, o Claude Code avisa que os conectores do
claude.ai ficam desabilitados.

## O que falta
Trocar o Bearer do dev pela chave da organização (`x-api-key`) no proxy e obter 200 do provedor. Sem
`ANTHROPIC_API_KEY` o teste não roda, e nenhum resultado foi inventado. Para fechar: fornecer a chave por variável
de ambiente e repetir `claude -p "responda só OK"` com o proxy em modo de injeção.

## Se falhar
O dev aponta o coding agent direto ao provedor (mitigação da ADR-0001) e o uso fica fora do gateway.

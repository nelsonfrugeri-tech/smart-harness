# H1 — Plugin com núcleo Agent Plugins e camada Claude Code no mesmo diretório

**Veredito: confirmada** (Claude Code 2.1.305, macOS arm64, 2026-10-20).

## Objetivo
Verificar se o Claude Code carrega, de `~/.claude/skills/<nome>/`, um diretório com o núcleo Agent Plugins
(`plugin.json`, `mcp.json`, `skills/`, `dev.smartharness/agents/`) e a camada Claude Code (`.claude-plugin/plugin.json`,
`.mcp.json`, `agents/`), sem erro e sem duplicação. Verificar se `SMART_HARNESS_TOKEN`, definido em `env` de
`~/.claude/settings.json`, chega como `Authorization: Bearer` a um MCP.
Código: `spikes/h1/probe/` e `spikes/h1/echo.mjs` (MCP de eco; registra só presença e tamanho do header).
Os nomes foram passados para inglês depois da execução (`sonda*` → `probe*`, `eco` → `echo`); a saída abaixo mostra os nomes usados na execução.

## Comandos e saída
```
$ claude plugin validate --strict spikes/h1/probe
✔ Validation passed                                   (exit 0)
$ claude plugin list --json        # após cp -R spikes/h1/sonda ~/.claude/skills/sonda-h1
{"id":"sonda-h1@skills-dir","version":"0.0.1","scope":"user","enabled":true,...}
$ claude -p ok --output-format stream-json --verbose  # mensagem init
skills: ["sonda-h1:sonda-skill"]   agents: ["sonda-h1:sonda-agent"]
mcp: [{"name":"plugin:sonda-h1:eco","status":"connected","source":"plugin"}]
```
Header recebido pelo eco (token aleatório de 32 caracteres):
```
{"method":"initialize","authPresent":true,"authLen":39,"bearerPrefix":true}
{"method":"tools/list","authPresent":true,"authLen":39,"bearerPrefix":true}
```
39 = `Bearer ` (7) + 32. Controle: com `env -u SMART_HARNESS_TOKEN claude -p ...` o header chegou com o mesmo tamanho;
o valor veio do `env` de `settings.json`, não do shell.

## Leitura do resultado
- Uma skill, um agent e um servidor MCP: `mcp.json` e `dev.smartharness/agents/` do núcleo não duplicam nada.
- O validador do Claude Code lê só `.claude-plugin/plugin.json`. O núcleo é validado pelo `harness validate`.
- O primeiro `--strict` falhou por falta de `author` (aviso vira erro). O gerador deve emitir `author`.
- Checks de diretório (LICENSE, ícone, privacidade) são informativos e não afetam o resultado.

## Versão mínima
Observada: **2.1.305**. Versões anteriores não foram testadas; a versão mínima real é desconhecida.

## Se falhar
Gerar dois artefatos (núcleo e camada Claude Code) e instalar só o da camada Claude Code (ADR-0001, Confirmação, hipótese 1).
